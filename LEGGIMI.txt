SASÀ CARS – sito statico HTML, CSS e JavaScript.

Aprire index.html nel browser oppure seguire README.md per il server locale.
Tutte le immagini sono nella cartella img: mantenerla insieme a css e js.

Il sito presenta le foto reali fornite e due auto in evidenza.
Prezzi e disponibilità sono su richiesta. Inserire recapiti aziendali verificati
nella configurazione CONTACT di js/main.js. Senza recapiti, il modulo scarica
una richiesta di testo e non invia messaggi. Con WhatsApp/email configurati
apre il servizio corrispondente per consentire al cliente di inviare.

GitHub Pages: ramo gh-pages, cartella / (root).
